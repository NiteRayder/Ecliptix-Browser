# Meridian
Android browser on GeckoView. Black / Grey / White / Silver theme.

Build: open in Android Studio (Koala+), sync, run. arm64-v8a only (edit app/build.gradle.kts for more ABIs).
Pin the GeckoView version in app/build.gradle.kts if you want reproducible builds.

Privacy: strict ETP, cookie isolation, social + fingerprinting protection, GPC, HTTPS-only, private tabs default.
Customization: top/bottom toolbar, accent colour, search engine, speed-dial start page, one-tap data clean.
