# Meridian

**A privacy-focused, customizable browser concept from Horizon Forge Studios.**

Meridian is a planned Windows browser project exploring a more configurable browsing experience, with privacy and user control as core design goals. It is part of the **Silverline Network** product family.

## Project status

The files in this repository currently contain an early browser-interface prototype and design references. **Meridian is not yet a complete, working browser**, and this repository does not yet contain a built Gecko-based browser engine or installer.

The interface prototype is intended to guide future implementation. The long-term technical direction is to build on Mozilla's Firefox/Gecko codebase rather than create a browser engine from scratch.

## Design direction

- **Palette:** black, white, and silver.
- **Style:** minimal, modern, professional, and software-focused.
- **Principles:** clear controls, restrained motion, readable contrast, and user-configurable presentation.
- **Product goals:** privacy, transparency, and meaningful customization.

Privacy features will be documented as they are implemented and tested. The project does not claim protections that are not yet present in working code.

## Roadmap

1. Establish a reproducible Windows build from the appropriate Mozilla source foundation.
2. Build and test an unmodified baseline.
3. Apply Meridian branding and integrate the interface design.
4. Review privacy-related defaults and optional components.
5. Test installation, browsing, updates, accessibility, and security.

- **Silverline Network** — the umbrella for the studio's software and products.
